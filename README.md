# Diego Gauto - Portfolio Profesional de Arquitectura e IA

Portfolio de Consultoría Técnica Senior bajo estándares de Arquitectura de Élite (Lighthouse 98-100) diseñado para posicionar a Diego Gauto como **Arquitecto de Software & Especialista en IA** ante CTOs, Engineering Managers y Tech Leads en LATAM y España.

## 📋 Documentación

- **[PRD (Documento de Requerimientos del Producto)](./docs/PRD.md)** - Documento completo de requerimientos, arquitectura y roadmap de implementación

## 🎯 Objetivo

Diferenciarse radicalmente del sitio actual (diegogauto.com) enfocado en emprendedores, creando un **portfolio de consultoría técnica** que demuestre:

- **Cómo piensa Diego** como arquitecto (decisiones, trade-offs, alternativas consideradas)
- Capacidad de diseñar **sistemas escalables** y **soluciones de IA** productizables
- Expertise en **Agentic Workflows**, **RAG** y arquitecturas complejas
- **Casos de Estudio de Arquitectura** con impacto medible en negocio

## 🏗️ Enfoque Diferencial

En lugar de una galería tradicional de proyectos con screenshots, este portfolio presenta **Casos de Estudio de Arquitectura** que muestran:

- 📊 **Contexto de Negocio** y desafío técnico
- 🎨 **Diagramas de Arquitectura** (flujos, decisiones de diseño)
- 💡 **Decisiones Técnicas Justificadas** con **Trade-offs** explícitos (por qué X en lugar de Y, ventajas/desventajas)
- 📈 **Impacto Medible** (performance, escalabilidad, ROI)

## 🏆 Principios de Arquitectura Élite

- ⚡ **Performance Extremo:** Lighthouse 98-100 (obligatorio)
- 🚫 **Cero Tolerancia a Tailwind CSS:** Control total sobre bundle size (< 100KB)
- 🔒 **TypeScript Estricto:** Prohibición absoluta de `any` - Bloqueo CI/CD
- 📝 **100% SSG Local:** Data estática en archivos `.ts`, cero dependencias externas
- 🎯 **Filtro Obligatorio de Leads:** Formulario de Calificación antes de acceso a Calendly

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 15 (App Router)
- **Estilos:** CSS Modules (⛔ Prohibido Tailwind CSS)
- **TypeScript:** Estricto (Prohibido `any` - Bloqueo CI/CD)
- **Deployment:** Vercel
- **Package Manager:** pnpm
